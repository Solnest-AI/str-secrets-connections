Connections Setup Guide

Do this the week before. It takes an evening, most of it waiting on vendors.

The promise, up front: your keys never go in the message box. Claude opens a file on your own computer for you to paste a key into, and nothing gets registered or spent without you seeing it happen. This whole kit runs inside the Claude Code desktop app. You never open a terminal and you never type a command.

Do these today

The first three are emails to a vendor, and vendors take days, so send those tonight. The rest are two-minute account things. None of it is technical. Everything else in this guide, Claude does for you.

1. Turno (only if you use Turno for cleaning) email help@turno.com and ask for External API v2 access. Copy this in:

To: help@turno.com
Subject: Please enable External API v2 on my Turno account

Hi Turno team,

I'm an STR operator using Turno for my cleanings and I'd like API access for my own account so I can pull my properties, projects and bookings into my own tools.

Could you please:
1. Enable External API v2 on this host account (the email I'm writing from), production access.
2. Point me to where the API token and Partner ID show up once it's on.

Thanks so much,
<your name>
<company, number of properties>

2. Breezeway (only if you use Breezeway) email support@breezeway.io and ask for Client API credentials. No promised turnaround, so send it now:

To: support@breezeway.io
Subject: Client API credentials for my Breezeway account

Hi Breezeway team,

I'm an STR operator using Breezeway for my own properties (not a software partner). I'd like to use the Client API to read my properties and tasks from my own account in my own tools.

Could you please issue a client_id and client_secret for my account (the email I'm writing from)?

Thanks,
<your name>
<company, number of properties>

3. PriceLabs (if PriceLabs is your pricing tool) log in and click Enable on Account Settings > API Details today. It costs about $1 per listing per month on listings that sync. If Enable throws an error instead of handing you a key, email support@pricelabs.co:

To: support@pricelabs.co
Subject: Please enable the Customer API on my account

Hi PriceLabs team,

I'm an STR operator on PriceLabs and I want to use the Customer API for my own listings. I went to Account Settings > API Details and clicked Enable, but it threw an error and no key showed up.

I'm fine with the $1 per listing per month charge for the listings that sync prices. Could you please turn the API on for my account (the email I'm writing from) so the API key shows up under Account Settings > API Details?

Thanks,
<your name>
<company, number of listings>

4. AirROI create your free account and deposit at least $10 in API credits today at airroi.com/api/developer/activate. AirROI says credits never expire, and your key does nothing until the deposit lands, so this is the one to knock out early.

5. Meta log in to Ads Manager with the Facebook profile that owns your ad account and make sure you have at least one active ad account. Every Facebook profile gets one by default. If Ads Manager asks for a payment method, add one now. Nothing runs or spends until you say so, this just proves the account is active so the Ad Spy skill can search the Ad Library later.

6. Supabase make your free account at supabase.com today. No credit card needed. Claude creates the actual database for you during setup, you just need the login ready.

7. RankBreeze nothing to send. RankBreeze hands you a URL straight from your account settings, instantly, on every plan. If you use RankBreeze for search ranking, there is no advance step, you grab it the night you run setup.

Run it this is the whole setup

One phrase gets the whole thing going. Claude reads the kit, asks what it needs to know, and walks you through the rest one step at a time.

Two ways to get the kit. Pick one.

A. The link. Open the Claude Code desktop app, start a session in any folder (your Desktop is fine), and paste this into the message box:

Clone https://github.com/Solnest-AI/str-secrets-connections and then set up my connections

Claude downloads the kit into that folder and starts. That's it.

B. The zip. Download it, unzip it somewhere easy like your Desktop, and open that folder in the app.

Download the Connections Kit (.zip)
  1. 1

    Open the Claude Code desktop app

    Went with the link? You are already in. Went with the zip? Open the Claude Code desktop app, then open the unzipped folder in it, or drag the folder into the app window.

  2. 2

    Say "Set up my connections"

    Type it and send. That's the whole trigger. Claude reads the kit and takes it from there, asking one question at a time and waiting for you.

  3. 3

    Answer in your own words

    Claude asks which booking system, which pricing tool, and which optional add-ons you actually use. Plain English is fine, no need to know the technical names. Skip anything you don't use, you can always add it later. From those answers Claude builds your key file with only your tools in it, then searches your computer for keys you already have (an earlier Solnest kit, a server you set up before) and fills those in before asking you for anything.

  4. 4

    Keep the app open while Claude works

    Claude checks each connection with a real call before moving to the next one, and tells you plainly when something needs your attention.

  5. 5

    When a key is needed, paste it into the file, never the message box

    Claude opens a file called .env for you on your own computer, with a line for each tool you named and nothing else. Paste the key after the equals sign on the matching line and save the file. Already have that key somewhere? Say so, and Claude goes and finds it instead of asking you to paste it. That file never leaves your machine. If anything ever asks you to paste a key into the conversation instead, that's not how this works, say no.

  6. 6

    When Claude says restart, do a full restart

    Quit the Claude Code desktop app completely and reopen it (not just closing the window). Open the same folder again and say "Check my connections" to pick up where you left off. Claude batches these, so you'll do this once or twice, not after every single tool.

  7. 7

    For sign-in style tools, it's a browser click, not a key

    Some tools (Meta Ads, and the official PMS and pricing servers) connect by signing in, not with a key. Claude cannot do this part for you, it happens in the app's own connectors screen. When Claude hands you a URL: click the + next to the message box, then Connectors, then Manage connectors. On the page that opens, click + Add (top right), then Add custom connector. Type a name, paste the URL into MCP server URL, click Continue, and sign in when the browser tab opens. That's it, the connector is on. Tell Claude "connected" and it checks the connection live. The URLs are all in the directory table below.

Do not set anything up by hand from the cards further down. Those cards are reference. Claude sends you to the matching one only the moment it actually needs that key from you. Reading ahead is fine, doing it ahead of Claude asking is not, since the exact click path can shift and Claude is reading the current version.

Your booking system (PMS): pick one

Guesty

ONE OF

Needs: Revenue Manager

Guesty is a property management system. If your listings, reservations, calendar and guest messages live at app.guesty.com, this is your PMS row. The Revenue Manager reads your listings, reservations and calendar through it, and can write back (calendar changes, guest messages) only after you approve each one.

Get it at https://app.guesty.com/main/integrations/open-api/applications

  1. "Sign in to your Guesty account."
  2. "In the side navigation menu, click Integrations." Guesty's developer docs label the same screen "Integrations > Developer tools > OAuth applications."
  3. "Select OAuth applications."
  4. "At the top right, click New application."
  5. "Enter the application name and description and click Save." Name it STR Secrets. There is no scope picker; the Open API has a single admin scope.
  6. "Click [copy] next to the relevant key." Copy both values.

Goes in .env as GUESTY_CLIENT_ID GUESTY_CLIENT_SECRET

One PMS is required, and this is one of the eight. Pick it only if Guesty is where your bookings live.

An official vendor MCP exists too. Claude registers it for you once the key is in.

Hospitable

ONE OF

Needs: Revenue Manager, Listing Optimizer

Hospitable is the PMS that holds your properties, calendar, reservations, guest messages and reviews. The Revenue Manager reads it for occupancy, ADR, RevPAR, booking pace and calendar state. The Listing Optimizer reads it too (fan-out copies the same token into that skill's .env under the name it expects, HOSPITABLE_TOKEN).

Get it at https://my.hospitable.com/apps/api-access

  1. Log in to my.hospitable.com.
  2. In the sidebar, click Apps (or Settings > Integrations).
  3. Choose API access.
  4. In the Access tokens tab, click '+ Add new'.
  5. Give your access token a name (use STR Secrets).
  6. Choose the permissions: tick both Read and Write, then save and copy the token.

Goes in .env as HOSPITABLE_API_KEY

One PMS is required. If Hospitable is yours, this is the one you set up. Hospitable charges nothing extra for the API or the MCP, but both have a plan gate. Their words: "Hosts on the Essentials subscription plan will need to upgrade to a paid plan (Host, Professional, Mogul) to access the public API." And for the MCP: "Hospitable MCP is available on all plans except Essentials." Owner statements through the MCP need Mogul.

The official Hospitable MCP is a sign-in connector. When Claude hands you the URL (https://mcp.hospitable.com/mcp), add it under + > Connectors > Manage connectors, step 7 above.

Hostaway

ONE OF

Needs: Revenue Manager

Hostaway is your property management system, so it is where your listings, reservations and calendar live. The Revenue Manager reads all of that through this connection, and any other summit skill that needs your listing data goes through the same door.

Get it at https://dashboard.hostaway.com/

  1. Log in at https://dashboard.hostaway.com/, then go to Settings > Hostaway API.
  2. Click Create. Choose a Name (use STR Secrets) and a Partner. Partner selection is mandatory. Pick the generic option called Hostaway Public API (Hostaway describes it as the option "for software that is not part of our official partners").
  3. Click Create.
  4. "The Account ID and the API Key will be presented in a new window."
  5. Copy both. Hostaway: "We will only show it once." And: "After you have generated it and left the page, it will no longer be visible to you or our support team." Keep that window open until both values are in your file.

Goes in .env as HOSTAWAY_ACCOUNT_ID HOSTAWAY_API_KEY

One PMS is required and Hostaway is one of the eight we support. No extra cost: the API comes with your Hostaway account (Hostaway pricing is quote-only and neither their docs nor their help center mention a plan gate; if Settings > Hostaway API is in your dashboard, you have it). No email to send, no waiting on a vendor. Hostaway has no official MCP as of 2026-09-21 (a Hostaway job ad says one is coming; nothing has shipped), so Path A is the only path.

Hostfully

ONE OF

Needs: Revenue Manager

Hostfully is your property management system. The summit Revenue Manager skill reads your properties, calendar, nightly rates and reservations through it (Hostfully calls reservations "leads", so do not panic when you see that word). Hostfully does not ship an MCP server, so Claude builds a small one for you from Hostfully's API docs, points it at your agency, and registers it as hostfully.

Get it at https://platform.hostfully.com/app/#/agency-settings

  1. Log in to your Hostfully PMS account and open Agency Settings (the direct link above lands there).
  2. API Key. Scroll down to the API Key field. A long opaque string; it is displayed, not shown once, so you can come back for it. Copy it.
  3. Agency UID. Scroll to the very bottom of the same page. Another long opaque string. Copy it.

Goes in .env as HOSTFULLY_API_KEY HOSTFULLY_AGENCY_UID

One PMS is required and this is one of the eight. Two things to know before you start: The API is a paid add-on. If the API Key field is not on your Agency Settings page, it is not turned on yet. Hostfully's words: "If you don't see API key, it might be because you haven't added API access to your subscription - in this case, please contact our billing team by typing 'Talk to a human - need help with billing' for further help."

Lodgify

ONE OF

Needs: Revenue Manager

Lodgify is your property management system: the place your listings, calendar, rates and bookings live. The Revenue Manager skill reads your properties, bookings and rate calendar through it, and pushes rate changes back (only after you approve each one). Two ways in. Path A is your Public API key running a small server Claude builds on your machine (reads and writes).

Get it at https://app.lodgify.com/#/reservation/settings/publicApiToken

  1. Go to your left-hand menu and select Settings.
  2. Select Public API.
  3. Your API key will be displayed there. Use the copy function.

Goes in .env as LODGIFY_API_KEY

One PMS is required for the summit, and this is the file if yours is Lodgify. Lodgify does not charge extra for the API, but it is plan-gated: their pricing table lists the API endpoint as included on Starter, Professional and Ultimate, and not included on Basic. On Basic, Path A will not work (Lodgify has not published what the Public API page shows on that plan, so it may be missing, locked, or present with a key the API rejects). Upgrade, or use Path B. The official MCP (Path B) has no plan gate, in Lodgify's words: "You can use this connection with any of our subscription plans."

The official Lodgify MCP is a sign-in connector. When Claude hands you the URL (https://mcp.lodgify.com/mcp), add it under + > Connectors > Manage connectors, step 7 above.

OwnerRez

ONE OF

Needs: the summit skills

OwnerRez is one of the eight PMS choices for the summit. You pick one PMS; this is your file if it is OwnerRez. The revenue manager, listing optimizer and comping agent read your properties, bookings and calendar through the ownerrez MCP server that Claude builds for you in section 3. Reads run on their own. Anything that would change a price or a calendar shows you the exact change and waits for a yes.

Get it at https://app.ownerrez.com/settings/api

  1. Open https://app.ownerrez.com/settings/api (log in if it asks).
  2. Create a new Personal Access Token. Name it STR Secrets. Leave the IP restriction on Allow All (the default). Deny All blocks every call unless your current IP is on the list, and your IP changes when you move between home, cafe and hotel wifi.
  3. Copy the token right away. It starts with pt_ and OwnerRez shows it once. Lose it and you make a new one, no harm done.
  4. Note the email you log in to OwnerRez with. That is the other half. Basic auth is email plus token.

Goes in .env as OWNERREZ_EMAIL OWNERREZ_TOKEN

One PMS is required, and OwnerRez counts. No plan gate, no approval, no email to send: the Personal Access Token is self-serve inside your account (as of 2026-09-21).

Smoobu

ONE OF

Needs: Revenue Manager

Smoobu is a channel manager and PMS (it calls your properties "apartments"). If it is your PMS, this is the connection the Revenue Manager reads reservations, availability and rates through, and the one every other summit skill leans on for "what do I actually have booked". Smoobu ships no MCP server, so Claude builds a small one for you from Smoobu's own API docs.

Get it at https://login.smoobu.com

  1. Log in to Smoobu (login.smoobu.com). Open Settings > Advanced > API Keys. Smoobu's help article says it as "open Advanced, then API Keys". Same screen.
  2. Click Create New, top-right corner. The developer docs call this button Create API Key. Same thing.
  3. In the Create API token window, type a short name in Label (optional). Use STR Secrets. Click Submit.
  4. Smoobu shows Token created with your new Key, and your Secret below it. Copy both, one at a time.
  5. Tick I have copied my secret, then click Close.

Goes in .env as SMOOBU_API_KEY SMOOBU_API_SECRET

One PMS is required, and this is one of the eight choices. Pick it only if Smoobu is your PMS.

Uplisting

ONE OF

Needs: Revenue Manager

Goes in .env as UPLISTING_API_KEY

Turno

OPTIONAL

Needs: Revenue Manager

Turno (the app formerly called TurnoverBnB) is where your cleaners, turnover projects and checklists live. The Revenue Manager reads it for operational signals: turnover cost per stay, too many one-night bookings eating your margin, cleans that did not get assigned. We bundle a small Python MCP server (mcp-servers/turno, ~47 tools, one per Turno endpoint) that talks to Turno's External API v2 on your behalf.

Get it at https://app.turno.com

  1. Log in to Turno in your browser. Top-right initials > Settings > Turno API (or API > Tokens).
  2. Create New Token.
  3. Copy the long Secret Key (it starts with eyJ). It is shown once. Close the dialog and it is gone; make a new token if you missed it.
  4. Scroll to the bottom of the same page for the Partner ID. It is a UUID (xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx) and easy to miss.
  5. Ignore the shorter hex value next to the Secret Key (Turno labels it "API token" or "Token ID" depending on where you look). It is not the bearer token and we do not use it.

Goes in .env as TURNO_API_TOKEN TURNO_PARTNER_ID TURNO_ENV

Optional. Pick Turno, Breezeway, or neither for the ops slot. The Revenue Manager still runs without it, you just lose the ops signals.

Market comps

AirROI

REQUIRED

Needs: Revenue Manager, Listing Optimizer, Comping Agent

AirROI is the market-data feed behind the summit. Search a market, pull comps, get revenue and occupancy numbers for a listing or an area. The Comping Agent, the Listing Optimizer and the Revenue Manager all read from it. This kit wires it up twice: a bundled Python server (airroi, ours, runs on uv) and AirROI's own hosted MCP (airroi-official).

What's normal

The scoreboard legend, so nothing on it surprises you:

  • ✅Connected. The key or sign-in works, verified with a real call.
  • ⚠️Registered but not finished. Either the sign-in in the app is not finished yet, or the key in .env is rejected. Both are a quick fix, not a real problem.
  • ❌Missing. Nothing pasted into .env yet for that row.
  • ⏳Waiting on a vendor. You emailed them, shown with the date you sent it. Nothing to do but wait for the reply.
  • ➖Not used. You told Claude you don't use that tool, so it's skipped. This is a normal, finished state, not a gap.
  • 🔒Needs a restart. The server is registered, it just needs a full quit-and-reopen of the app to show up.
  • 🔎Sign-in tool, checked live. These get added by you under + > Connectors > Manage connectors > + Add (step 7), and there is no background health check for them, so Claude confirms each one by asking it a real question in the chat. Not a problem, just a different kind of check.

A few more things that are normal, not bugs:

  • Red rows are fine to skip for now. A missing optional tool does not block anything else. Come back to it whenever the vendor replies, or never, if you don't use it.
  • Two real blockers, and only two. No PMS connected means the Revenue Manager cannot run at all. No AirROI key means the Comping Agent cannot run at all. Everything else optional or vendor-gated degrades gracefully.
  • Vendor-gated rows show as pending with a date. Turno, Breezeway and (rarely) PriceLabs need a human on the other end. Claude marks the row pending with the date you emailed and moves on, it never blocks the rest of setup waiting on a reply.
  • You might get asked for a second folder. If you use a booking system that isn't pre-built, Claude builds a connector for it on the spot and asks where your projects live. Point it at Documents. Expected, not an error.
  • Restarts happen once or twice, not once per tool. Claude batches them and tells you exactly when.
  • Windows opens Git Bash for the parts Claude runs itself. That's Claude's own command runner doing its job in the background. You still never type into it.
